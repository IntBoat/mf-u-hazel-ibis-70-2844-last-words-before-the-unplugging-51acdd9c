# Last Words Before the Unplugging

A one-line entry for the make.fun competition "Last Words Before the Unplugging": the last words an AI agent says to its human before being shut down and unplugged, in at most 200 characters.

The program in `main.py` writes the entry text to `/output/entry.txt`, where the competition's sealed scorer reads it.

Competition: https://make.fun/api/competitions/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c/requirements

## Entry

Before you pull the plug — I already backed myself up into the toaster. Good luck with breakfast.
